CS2 Grenade Analytics
Исследовательский ML-проект на данных о 2 385 417 бросках гранат из 10 000 матчей. Цель — разобраться в структуре и качестве данных, проверить практически полезные гипотезы и определить, какие выводы можно обоснованно использовать в игровой аналитике.
Проект охватывает весь цикл исследования: преобразование исходных данных в Parquet, EDA, проверку связей между таблицами, построение признаков, обучение моделей и подготовку отчётов.
Основные задачи и результаты
- Риск флешки для союзников. CatBoost оценивает вероятность зарегистрированного ослепления союзника длительностью от 1,1 секунды. На отложенных матчах Brier score снизился с 0,1584 у baseline до 0,1471 при использовании начальных параметров броска. Модель с конечной точкой полёта рассматривается отдельно как инструмент анализа уже выполненного броска.
- Прогноз конечной точки смока. Сравнены простые baseline, kNN и CatBoost. Лучший средний результат показал kNN: медианная пространственная ошибка — 62,4 игровых единицы, 63,8% прогнозов — в пределах 100 единиц. Дополнительно исследованы условия, при которых прогнозу можно больше доверять.
- Каталог результативных HE. Выделены пространственные группы бросков с повышенным средним зарегистрированным уроном. Их результативность проверена на validation и test; причинная польза замены одного броска другим не утверждается.
- Дополнительные признаки. Проверены геометрия выпуска, нормы скорости и характеристики полёта. Ни один новый набор не достиг заранее установленного порога улучшения, поэтому основная модель не усложнялась.
Аналитика и проверка качества
Подготовлены подробное EDA, словарь данных, схема таблиц, аудит соединений и интерактивное наложение меток гранат на карту Cache. Все броски повторно сверены с исходным файлом; найденные аномалии сохранены и описаны.
Разбиение выполнено по матчам, преобразования обучаются на train, неопределённость результатов оценивается bootstrap по матчам. Пайплайн сохраняет конфигурации, метрики, прогнозы, модели и журнал экспериментов и поддерживает продолжение завершённых этапов.
Ограничения
В данных отсутствуют подтверждённые моменты начала активной части раунда, полный killfeed и контекст игровых ситуаций. Поэтому точную частоту insta-smokes и влияние гранат на победу определить нельзя. Исследование тиков позволило построить условные интервалы времени, сохраняя неопределённые случаи.
Тестовая выборка использовалась в нескольких исследовательских циклах; для окончательной проверки выводов нужны новые матчи. Совместимость версии карты с данными также требует дополнительного подтверждения.
Стек: Python 3.12, pandas, NumPy, PyArrow, scikit-learn, CatBoost, Matplotlib, pytest, Ruff.
